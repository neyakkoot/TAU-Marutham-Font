# TAU-Marutham Font

## About This Repository

This repository provides the original TAU-Marutham Tamil Unicode font (`.ttf`) for easy access and download by the public.

The original font is provided by the Government of Tamil Nadu through the Tamil Virtual Academy.

## Original Font Details

- Font Name: TAU-Marutham
- Font Type: Tamil Unicode
- File Format: TrueType Font (.ttf)
- Original Provider: Tamil Virtual Academy
- Government: Government of Tamil Nadu

## Official Source

https://www.tamilvu.org/

## Purpose of This Repository

The purpose of this repository is to make the original TAU-Marutham font easily accessible to students, teachers, researchers, developers and Tamil computing enthusiasts.
