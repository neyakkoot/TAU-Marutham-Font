# TAU-Marutham எழுத்துரு

## இந்தக் களஞ்சியத்தைப் பற்றி

இந்தக் களஞ்சியம், அசல் TAU-Marutham தமிழ் யூனிகோடு எழுத்துருவை (`.ttf`) பொதுமக்கள் எளிதாக அணுகவும் பதிவிறக்கம் செய்து பயன்படுத்தவும் உதவும் வகையில் வழங்குகிறது.

இந்த எழுத்துரு தமிழ்நாடு அரசின் சார்பில் தமிழ் இணையக் கல்விக்கழகத்தால் வழங்கப்பட்டுள்ளது.

## அசல் எழுத்துரு விவரங்கள்

- எழுத்துருவின் பெயர்: TAU-Marutham
- எழுத்துரு வகை: தமிழ் யூனிகோடு
- கோப்பு வடிவம்: TrueType Font (.ttf)
- அசல் வழங்குநர்: தமிழ் இணையக் கல்விக்கழகம்
- அரசு: தமிழ்நாடு அரசு

## இந்தக் களஞ்சியத்தின் நோக்கம்

மாணவர்கள், ஆசிரியர்கள், ஆய்வாளர்கள், மென்பொருள் உருவாக்குநர்கள் மற்றும் தமிழ் கணினி ஆர்வலர்கள் அசல் TAU-Marutham எழுத்துருவை எளிதாக அணுகிப் பயன்படுத்துவதற்கு உதவுவதே இந்தக் களஞ்சியத்தின் நோக்கமாகும்.

## பதிப்புரிமை, உரிமம் குறித்த அறிவிப்பு

அசல் TAU-Marutham எழுத்துரு இந்தக் களஞ்சியத்தின் நிர்வாகியால் உருவாக்கப்பட்டதல்ல; அதற்கான உரிமையும் நிர்வாகியிடம் இல்லை.

அசல் எழுத்துரு தொடர்பான அனைத்து உரிமைகளும் அந்தந்த உரிமையாளர்களிடமே தொடர்ந்து இருக்கும்.

இந்தக் களஞ்சியம் அசல் எழுத்துருவின் உரிமையைத் தனதாக்கிக் கோரவில்லை; மேலும், அதற்கென எந்தப் புதிய உரிமத்தையும் வழங்கவில்லை.

பயனர்கள் எழுத்துருவைப் பயன்படுத்துதல் மற்றும் மறுபகிர்வு செய்தல் தொடர்பான நிபந்தனைகளுக்கு, அசல் வழங்குநரின் விதிமுறைகளையும் பொருந்தக்கூடிய அரசு ஆணைகளையும் அணுகுமாறு கேட்டுக்கொள்ளப்படுகிறார்கள்.

## நன்றியுரை

தமிழ் யூனிகோடு எழுத்துருக்களைப் பொதுமக்களின் பயன்பாட்டிற்காக வழங்கிய தமிழ்நாடு அரசுக்கும் தமிழ் இணையக் கல்விக்கழகத்திற்கும் எங்களது மனமார்ந்த நன்றியைத் தெரிவித்துக்கொள்கிறோம்.

# TAU-Marutham Font

## About This Repository

This repository provides the original TAU-Marutham Tamil Unicode font (`.ttf`) for easy access and download by the public.

The original font is provided by the Government of Tamil Nadu through the Tamil Virtual Academy.

## Original Font Details

- Font Name: TAU-Marutham
- Font Type: Tamil Unicode
- File Format: TrueType Font (.ttf)
- Original Provider: Tamil Virtual Academy
- Government: Government of Tamil Nadu

## Official Source

https://www.tamilvu.org/

## Purpose of This Repository

The purpose of this repository is to make the original TAU-Marutham font easily accessible to students, teachers, researchers, developers and Tamil computing enthusiasts.
